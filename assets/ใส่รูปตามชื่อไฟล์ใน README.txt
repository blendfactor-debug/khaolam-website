# วิธีใช้ไฟล์เว็บไซต์เวอร์ชันแก้ไข

1. นำไฟล์ `index.html` ใหม่นี้ไปแทนไฟล์เดิม
2. วางรูปสินค้าไว้ในโฟลเดอร์ `assets`
3. เปลี่ยนชื่อรูปให้ตรงตามนี้

## ชื่อไฟล์รูปที่เว็บไซต์เรียกใช้

- `assets/hero.jpg` = ภาพใหญ่ด้านบนเว็บ
- `assets/crispy-khao-lam.jpg` = รูปสินค้า Crispy Khao Lam
- `assets/khaolam-tan.jpg` = รูปสินค้า ข้าวหลามแต๋น
- `assets/gift-set.jpg` = รูปเซ็ตของฝาก
- `assets/package.jpg` = รูปแพ็กเกจสินค้า
- `assets/shop.jpg` = รูปหน้าร้าน/จุดจำหน่าย

ถ้ายังไม่มีบางรูป เว็บไซต์จะซ่อนรูปที่ไม่มีให้อัตโนมัติ ไม่ทำให้หน้าเว็บพัง
